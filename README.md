# Ratmaze 🧀 [WIP]

> A 2D arcade game built in JavaFX, demonstrating core Object-Oriented Programming principles and custom game mechanics. 

**🚧 Work In Progress:** This project is currently under active development as a semester assignment for the Java programming course at VŠB-TUO. Features and mechanics are continuously being implemented and refined.

## ✨ Current & Planned Features
- **Custom Game Engine Logic:** Built purely with JavaFX, handling the main game loop and screen updates.
- **Entity Movement & Physics:** Implementation of bounding box physics for smooth entity movement and precise collision detection.
- **Sprite Rendering:** Managing and rendering 2D graphics and animations for the player and game environment.
- **OOP Architecture:** Clean class hierarchies for game entities, separating logic, rendering, and input handling.

## 🛠️ Tech Stack
* **Language:** Java
* **Framework:** JavaFX
* **Concepts:** Object-Oriented Programming (OOP), Collision Detection, 2D Rendering
